Originalvorlagen aus beiden Matrizen 1.4. Wähle einen Shake oder Drink, passe Mengen innerhalb der Quellbereiche an und speichere ihn als eigenes Rezept. Medizinische Aussagen der Quelldokumente werden hier nicht neu bewertet.

Über die Vorschau werden zwölf Startvarianten ergänzt. Alle vierzehn Vorlagen stehen hier zur Auswahl. Zwei Kraft-Drinks benötigen noch das Portionsgewicht von Bulk Plus. Fehlende Nährwerte bleiben unbekannt.

Daten sichern und übertragen

Alle Daten werden lokal auf diesem Gerät gespeichert. Sichere sie regelmäßig als JSON-Datei; Browserdaten können gelöscht werden.

Import ergänzt vorhandene Daten. Identische Einträge werden übersprungen, abweichende ID-Konflikte als Kopien erhalten. Vor der Übernahme wird eine lokale Sicherung angelegt.

Installation auf Android

Die App muss über HTTPS bereitgestellt werden. Danach in Chrome öffnen und über das Browsermenü „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ auswählen. Eine lokal geöffnete HTML-Datei ist noch keine installierte PWA.
