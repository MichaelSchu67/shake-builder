Rezeptbaukasten

Zutaten

Nährwerte pro Rezept

Alle Werte sind Schätzwerte. Fehlende Mikronährstoffdaten werden nicht als Null interpretiert. Keine medizinisch vollständige Formula-Diät.

Produktdatenbank

Leere Felder bedeuten unbekannt. Bei Makronährstoffen bitte alle vorhandenen Angaben ergänzen. Für Flüssigkeiten erfolgt die Rezeptberechnung in ml.

Produkte

Daten sichern und übertragen

Alle Daten werden lokal auf diesem Gerät gespeichert. Sichere sie regelmäßig als JSON-Datei; Browserdaten können gelöscht werden.

Import ersetzt die gesamte lokale Produkt- und Rezeptdatenbank. Vorher eine Sicherung exportieren.

Installation auf Android

Die App muss über HTTPS bereitgestellt werden. Danach in Chrome öffnen und über das Browsermenü „App installieren“ bzw. „Zum Startbildschirm hinzufügen“ auswählen. Eine lokal geöffnete HTML-Datei ist noch keine installierte PWA.
